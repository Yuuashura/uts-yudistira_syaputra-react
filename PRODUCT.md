# KopiKu
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Proyek UTS React Fundamental milik Yudistira Syaputra. Pengunjung menjelajahi 15 menu, mengulas, menyimpan favorit, dan melakukan transaksi simulasi. Penguji memeriksa kepatuhan PDF.

## Confirmed scope
Pengguna menyetujui eksekusi seluruh delapan tahap plan.md. PDF menjadi sumber utama; rincian penerimaan ada di prd.md. React 19, Vite 5, pnpm; seluruh CSS di src/index.css; seluruh ikon lucide-react; foto JPG lokal asli. Tanpa backend, CDN CSS/font, pembayaran nyata, dan API menu runtime.

## Brand commitments
Nama KopiKu. Permintaan terbaru: tampilan mewah/luxury. Arah implementasi yang diumumkan: espresso, ivory, brass. Bahasa Indonesia, informasi simulasi transparan. Data harga dan rating awal merupakan demo, bukan klaim usaha nyata.

## Workflow
Pencarian/filter → detail/favorit/ulasan → keranjang → promo → pembayaran simulasi → struk/riwayat. Penyimpanan lokal dan reset aman. Akses keyboard, modal fokus terkelola, responsif.

## Assumptions
Promo dan pajak mengikuti asumsi terdokumentasi pada prd.md. Tidak ada testimoni pelanggan nyata, alamat usaha, atau klaim penjualan yang diberikan.
